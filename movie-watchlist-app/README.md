# 🎬 Movie Watchlist Tracker (Full-Stack REST API)

เว็บแอปพลิเคชันจัดการรายการภาพยนตร์ส่วนตัว พัฒนาด้วย Node.js, Express.js และ Vanilla HTML/CSS/JavaScript รองรับการทำงานแบบ CRUD ครบถ้วนผ่าน REST API

## 🛠️ วิธีการติดตั้งและการรันโปรเจกต์

1. ติดตั้ง Dependencies:
   ```bash
   npm install
2. รันเซิร์ฟเวอร์:
   ```bash
   node server.js
เปิดเบราว์เซอร์ไปที่: http://localhost:3000
